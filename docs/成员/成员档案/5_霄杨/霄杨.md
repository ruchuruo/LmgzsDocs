== (1)《粉裙下的英雄》
```c
作者: 糯糯
主角: 云飞扬
路人: 小李
```

云飞扬 发现，除了他自己，几乎没有其他玩家上线。这让他感到非常失落，
毕竟，创建游戏服务器的目的就是为了与朋友们一起享受游戏的乐趣。

就在他一筹莫展时，群里的小李突然冒了出来，还带着一丝不怀好意的笑：“飞扬，想让我们全上线陪你炸服？行啊，只要你周末穿我送你的那套女装直播，我们立马归位！”

云飞扬 想都没想就直接回到：“你这是什么话！”

说起那套女装，还是生日时小李 “精心” 送的礼物，从那以后，小李就天天念叨着想看他穿，可 云飞扬 每次都义正言辞地拒绝：“不行！我从不干社死的事！”

随后的几天，云飞扬 还是在想着如何让玩家上线的办法，但是这些办法中多出了一个穿女装的选项，一想到这个选项，云飞扬 总是摇摇头说道：“绝对不行”。

一天
“这怎么行！”

两天
“这不太好......”

三天
“也就只能想想，绝对不行！”

四天
“实在没辙了再说，先放最后。”

五天
“要不试试？”

六天
“干了！”

曾经高高立起的 “绝不社死” flag，在空荡荡的服务器面前，轰然倒塌。

直播前的房间，暖黄灯光裹着满室紧张。

云飞扬 攥着那套粉色萝莉裙，站在镜子前长舒一口气，心里又尴尬又无奈，谁能想到，一向标榜 “不社死” 的自己，居然会为了服务器，被迫做出这个决定。

柔软的布料贴合身体，带来一种全然陌生的触感，别扭又滑稽。他手忙脚乱地调整着裙摆，小心翼翼地别上精致的发夹。当他抬头看向镜中的自己时，那个陌生又娇俏的模样，让他瞬间脚趾抠地，恨不得当场找个地缝钻进去。

== (2)《你准备挨*吧》
```c
作者: 糯糯
主角: 云飞扬
配角: 绮纱
路人: 张三
```

张三停下脚步，向云飞扬微微欠身，用一种恭敬而又不失冷峻的语气说道：“飞扬哥，我们已经按照您的指示，将那个小鬼带来了” 云飞扬微微点了点头，对张三和他的帮手表示了认可：“你们做得很好，辛苦了。”他的声音低沉而有力，透露出一种威严和不可抗拒的力量。

昏黄的灯光勉强照亮了四周，空气中弥漫着一股陈旧与霉湿的味道。云飞扬站在一张破旧的木桌旁，桌上整齐的摆放着一排不可名状之物，他的目光如鹰隼般锐利，紧盯着对面那个瑟缩在角落里的少女。

她感到自己的嚣张气焰在 云飞扬 的目光下逐渐消散，取而代之的是无尽的恐惧和悔恨。

少女名叫绮纱，脸上满是惊恐与不安，他瘦弱的身躯在宽大的衣衫下显得格外单薄，双手紧握成拳，指节因用力而泛白。

是时候给她一个深刻的教训了，轻轻捏住了绮纱的下巴，迫使她抬头与自己对视。

“可恶的小鬼，你也不想这件事情被别人知道吧”
云飞扬嘴角勾起一抹冷笑，言语间透露出不容置疑的寒意。他的声音在空旷的地下室里回荡，如同锋利的刀刃，切割着每一寸空气，让人心生寒意。

绮纱的喉咙像是被什么东西卡住了一般，发不出半点声音，只能无助地点点头，眼中满是祈求与绝望。他明白，云飞扬的话不仅仅是威胁，更是一种冷酷的宣判，自己的命运已经掌握在了这个男人的手中。

“虽然晚了些但端午还是要有仪式感，粽叶、糯米、蜜枣都准备好了，还剩一样东西就交给你了”云飞扬嘴角勾起了一丝弧度，坏笑着说道。

“你就准备艾草吧！”

“我……我错了， 云飞扬 哥哥，求你别这样……”她的眼神中充满了恐惧和绝望。

“现在，到我来教训你了！” 云飞扬 的声音冷冽如冰，他松开了绮纱的下巴，随即猛地从身旁抓起了棍棒，把她推倒在地，手上的棍棒犹如龙腾虎跃般迅猛挥击，每一次敲打都留下深深的痕迹，轨迹交错间，幻化出一道道残影，伴随着沉闷而有力的咚咚声。

“呜哇啊啊啊 ♥大哥哥我错了! ~♥不要、不要再用棍棒拷打我了~ ♥要去了!!!♥呜呜......♥人渣，变态，废物..…...实在是♥，烂透了!♥”

== (3)《雷霆少年的告白乌龙》
```c
作者: 望驳讨
主角: 云飞扬(飞扬)
配角: 糯, 雨儿(雨姐)
```

橘红的阳光，穿透那劣制的玻璃照射而下，正巧打在了那摆着雷霆坐姿的云飞扬脸上，将那张带着六分傲慢，六分潇洒，一分冷淡以及二分带着笑意的脸上。看着坐在旁边的几个二货朋友，云飞扬微微笑着。

“真是碧阳的晚意，初生的东曦。”

云飞扬脑海里浮现了一个美丽的身影，那是他喜欢的女孩。

她如绵花一般绚烂，总是在云飞扬伤心难过之时给予其最温暖有力的怀抱。

一想起她，云飞扬的嘴角便又抬起了笑容，为什么想起她呢？因为今天云飞扬便准备向她进行表明，她在他在心中的重量使其早己安排好了一切。

如今即将放学，也就要快到了与她相见的重心时刻，而比同时也他那颗充满爱意的心脏也随着时间的流逝加快了跳动的频率。

“叮——下课时间到了，老师辛苦了。”

“哦，多么美好的时间啊，终于来到了爱的时间了吗！”云飞扬高兴道。一边说一边对着镜子整理起了服饰，准备以最完美的姿态迎接他所喜爱的人。顺手拿起桌上的水乳茶，打口喝了一口润了润喉咙。

“哦，吊~man！多么美味啊！也只有这样的佳酿才配得上我这样的人儿~”

就这样，云飞扬向着他的珍爱出发了，但云飞扬不知道的是，他心心念念的人儿遇到了一只叫“糯”的猫，随着“糯”的尾巴一扬，她的脑中思想出现了一些变化，她的飞扬哥哥似乎变成了一个浪荡子。

一会儿后。

穿着一丝不苟的云飞扬终于在他们约好的地方后面不远处看到了那人群中最艳丽的花，于是他提这为她专门定制的礼物走了过去。

而她也看到了她云飞扬哥哥，在那一瞬间，她的眼睛红了，她无法想象他那温柔、阳光下的飞扬哥哥竟然是一个浪荡子。

云飞扬终于来到了她的面前，看到她那发光发红的眼睛还以为是她被感动到了。

“雨儿，这是我为你定制的46码的高跟鞋，请你尝试喜欢我吧！”

边说着，云飞扬单膝跪在地上，真诚的看着雨儿。

只见雨儿羞怒的说道：“我怎么喜欢你这浪荡的人。”说一记清脆的耳光出现在了云飞扬的脸上，一耳光后她便伤心的跑走了。

云飞扬重新站起，回味着刚才的一幕。

突然他感叹到：“哦！她刚才说喜欢我耶！”然后便走向了追寻雨姐的路上

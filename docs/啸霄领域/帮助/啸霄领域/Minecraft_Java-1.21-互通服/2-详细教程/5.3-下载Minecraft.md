### 目录结构
你现在的目录应该是这样的
```c
└─📁Minecraft Java
   ├─📁.minecraft
   │   │      📄launcher_profiles.json
   │   │
   │   ├─📁assets
   │   ├─📁libraries
   │   └─📁versions
   │       └─📁1.20.1_Forge
   │              ☕1.20.1_Forge.jar
   │              📄1.20.1_Forge.json
   |
   ├─📁HMCL
   |      📄hmcl.json                              启动器配置文件
   |      ▶️HMCL-<version>.exe                    启动器
   |
   └─📁PCL
       |  ▶️Plain Craft Launcher <version>.exe    启动器
       |
       └─📁PCL                                     启动器配置文件夹
```

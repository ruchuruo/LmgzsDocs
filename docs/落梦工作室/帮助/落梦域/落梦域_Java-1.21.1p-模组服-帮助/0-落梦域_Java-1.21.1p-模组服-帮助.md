## 建筑迁移
使用 [MCA Selector](https://github.com/Querz/mcaselector)

在开服一段时间后，会将观赏性的建筑迁移到同一个地方，
比如:
```c
a建筑坐标 100, 100, 100
b建筑坐标 200, 100, 200
c建筑坐标 300, 100, 300

↓ 迁移

旧建筑据点 10000, 10000, 10000
```

旧建筑据点优先挑选宽阔海域的海岛上，手动摆放位置(x, z)，可以使用环境改造枪修饰地形

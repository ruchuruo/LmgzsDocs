```c
└─📁web             网站根目录
   ├─📄index.html   首页
   ├─📁files        存放文件
   └─📁theme        主题
```

## oupala/apaxy
::: info
- [github](https://github.com/oupala/apaxy)
- [./README.md](./apaxy/README.md)
:::
::: info 需求
- Apaxy 需要 Apache (2.4+) http 服务器
- Apache HTTP 服务器的配置中必须为 Apaxy 样式文件夹设置
```apache
AllowOverride Options Indexes FileInfo
```
:::

### 手动安装
1. 下载 Apaxy
- 在 github 选择 main 分支
- `Download ZIP`

2. 解压缩 .zip
- 解压后的目录结构
```c {14}
└─📁apaxy-main
   ├─📄.gitignore
   ├─📄apaxy-configure.sh
   ├─📄apaxy.config
   ├─📄CHANGELOG.md
   ├─📄CODE_OF_CONDUCT.md
   ├─📄CONTRIBUTING.md
   ├─📄COPYING.md
   ├─📄docker-compose.yml
   ├─📄Dockerfile
   ├─📄package.json
   ├─📄README.md
   ├─📁.github
   ├─📁apaxy
   └─📁share
```

3. 将 `apaxy` 文件夹复制并粘贴到 `theme` 文件夹
```c {5}
└─📁web             网站根目录
   ├─📄index.html   首页
   ├─📁files        存放文件
   └─📁theme        主题
      └─📁apaxy
```

4. 替换文件中的关键字
- `{FOLDERNAME}` 替换为 实际路径
- 需要替换的文件
```c {6,9-14,18-19}
└─📁web             网站根目录
   ├─📄index.html   首页
   ├─📁files        存放文件
   └─📁theme        主题
      └─📁apaxy
         ├─📄htaccess.txt
         └─📁theme
            ├─📄.htaccess
            ├─📄400.html
            ├─📄403.html
            ├─📄404.html
            ├─📄408.html
            ├─📄500.html
            ├─📄502.html
            ├─📄apaxy-lightgallery.js
            ├─📄apaxy.js
            ├─📄favicon.ico
            ├─📄footer-lightgallery.html
            ├─📄footer.html
            ├─📄header-lightgallery.html
            ├─📄header.html
            ├─📄style.css
            └─📁icons
```

- 示例
```apache {3}
# apaxy/htaccess.txt

#ErrorDocument 400 {FOLDERNAME}/theme/400.html
ErrorDocument 400 /theme/apaxy/theme/400.html
```

5. 将 `apaxy/htaccess.txt` 文件剪切到网站根目录 并改名为 `.htaccess`
```c {2}
└─📁web             网站根目录
   ├─📄.htaccess
   ├─📄index.html   首页
   ├─📁files        存放文件
   └─📁theme        主题
```

可选 推荐 启用 JavaScript灯箱画廊
::: info lightgallery.js
- [github](https://github.com/sachinchoolur/lightgallery.js/)
- [官网](https://sachinchoolur.github.io/lightgallery.js/)
:::

- 示例
```apache
# .htaccess

#HeaderName {FOLDERNAME}/theme/header.html
#ReadmeName {FOLDERNAME}/theme/footer.html
HeaderName /theme/apaxy/theme/header-lightgallery.html
ReadmeName /theme/apaxy/theme/footer-lightgallery.html
```



### 自定义样式
1. 创建样式文件
```c {22-23}
└─📁web             网站根目录
   ├─📄index.html   首页
   ├─📁files        存放文件
   └─📁theme        主题
      └─📁apaxy
         ├─📄htaccess.txt
         └─📁theme
            ├─📄.htaccess
            ├─📄400.html
            ├─📄403.html
            ├─📄404.html
            ├─📄408.html
            ├─📄500.html
            ├─📄502.html
            ├─📄apaxy-lightgallery.js
            ├─📄apaxy.js
            ├─📄favicon.ico
            ├─📄footer-lightgallery.html
            ├─📄footer.html
            ├─📄header-lightgallery.html
            ├─📄header.html
            ├─📄main.css
            ├─📄style-custom.css
            ├─📄style.css
            └─📁icons
```

2. 在 `style-custom.css` 中填写自定义样式

3. 将 `style.css` 和 `style-custom.css` 中的内容合并到 `main.css`
- `style.css` 中的内容在前
- `style-custom.css` 中的内容在后

4. 修改配置文件
- 示例
```apache
# .htaccess

#IndexStyleSheet {FOLDERNAME}/theme/style.css
IndexStyleSheet /theme/apaxy/theme/main.css
```

::: info 问答
- 为什么不在 `main.css` 中 import 多个 CSS
    - 进入或返回目录时，会重新下载 import 的 CSS，导致闪烁
:::

# 虚拟主机
::: info
- Virtual Host 虚拟主机
- 同一 IP、不同端口、不同网站
:::





## Windows
1. 修改配置文件
- 打开 `httpd.conf`

监听端口，注释，之后可以在 vhosts 中填写
```apache {2}
#Listen 12.34.56.78:80
#Listen 80
```

虚拟主机，自定义配置文件目录
```apache {3}
# Virtual hosts
#Include conf/extra/httpd-vhosts.conf
Include conf/vhosts/*.conf
```

2. 创建目录 和 配置文件
- 方案1，`Listen` 填写在各站点配置文件中
```c
conf/vhosts/site1.conf
conf/vhosts/site2.conf
```
```c
└─📁conf
   └─📁vhosts
      ├─📄site1.conf
      └─📄site2.conf
```

- 方案2，`Listen` 填写在一个文件中
```c
conf/vhosts/Listen.conf
conf/vhosts/site1.conf
conf/vhosts/site2.conf
```
```c
└─📁conf
   └─📁vhosts
      ├─📄Listen.conf
      ├─📄site1.conf
      └─📄site2.conf
```

3. 填写配置文件
```c
conf/vhosts/site1.conf
```
```apache
Listen 8881

<VirtualHost *:8881>
    DocumentRoot "D:/web/site1"
    ServerName localhost
    <Directory "D:/web/site1">
        Options None
        AllowOverride None
        Require all granted
    </Directory>
</VirtualHost>
```

4. 重启 Apache

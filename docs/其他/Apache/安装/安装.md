# 安装
::: info
官网: https://httpd.apache.org/
:::





## Windows
### 下载
1. 打开官网

2. 点击侧栏 `Download!`
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/1.png)

3. 选择 `Files for Microsoft Windows`
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/2.png)

4. 选择 `Apache Lounge`
- 跳转到 `https://www.apachelounge.com/`
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/3.png)

5. 按需选择 `Win64` 或 `Win32`
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/4.png)

### 安装
1. 将下载的 `.zip` 放到任意目录
- 例如: `D:\Apache\`

2. 解压 `.zip`
```c
└─📁Apache
   └─📁httpd-2.4.68-260617-Win64-VS18  // [!code ++]
```

3. 阅读 `ReadMe.txt`
```c {4}
└─📁Apache
   └─📁httpd-2.4.68-260617-Win64-VS18
      ├─📄-- Win64 VS18  --
      ├─📄ReadMe.txt
      └─📁Apache24
```
```c
17 June 2026 Update
......

Install
安装
-------

......

  When you unzip to an other location: 
  当您解压缩到其他位置时
  change Define SRVROOT "c:/Apache24"  in httpd.conf, for example to "E:/Apache24"
  修改 httpd.conf 中定义的 SRVROOT "c:/Apache24", 例如修改为 "E:/Apache24"

......
```

4. 修改配置文件
- 打开 `httpd.conf`
```apache {2}
#Define SRVROOT "C:/Apache24"
Define SRVROOT "D:\Apache\httpd-2.4.68-260617-Win64-VS18\Apache24"
```

### 启动
1. 进入目录
```c
httpd-2.4.68-260617-Win64-VS18/Apache24/bin
```
```c {7}
└─📁Apache
   └─📁httpd-2.4.68-260617-Win64-VS18
      ├─📄-- Win64 VS18  --
      ├─📄ReadMe.txt
      └─📁Apache24
         ├─📄......
         ├─📁bin
         │  ├─📄......
         │  └─▶️httpd.exe
         │
         └─📁......
```

2. 执行命令
```ps
./httpd.exe
```

3. 打开浏览器并键入地址来测试您的安装
```c
http://localhost
```

### 关闭
按 Ctrl+C 可以关闭 Apache (可能需要几秒钟)

# 传文件

不要把所有的鸡蛋放进一个篮子

压缩包与密码分开发

张三 想要发送一个 `学习资料.zip` 给 李四，张三 不信任当前使用的社交平台，张三 尝试使用以下方法

### 发压缩包
张三 在当前社交平台发送加密的 `学习资料.zip`

### 发送密码
张三 在另一个平台发送压缩包密码，并且拆分发送，只发送一半

以某个 网页剪贴板 为例
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/1.png)

张三 在 `Code` 处填写 内容访问密码，在 `文本` 处填写 压缩包密码，之后点击 `保存`

`ABCDEFGH` 为 内容访问密码，`1234567890` 为 压缩包密码前段
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/2.png)

假设这个网页的 URL 是 `https://example.com`，保存内容后，可能会变成 `https://example.com/#ABCDEFGH`

张三 将这个网页的 URL 通过社交平台发送给 李四，不过 张三 在发送前对 URL 进行了处理，将 URI 给删除了，所以张三发送的 URL 是 `https://example.com`

张三 将 内容访问密码 通过社交平台发送给 李四，内容访问密码 是 `ABCDEFGH`

张三 将 压缩包密码后段 通过社交平台发送给 李四，压缩包密码后段 是 `qwer`

### 接收内容
李四 在社交平台收到了 张三 发来的内容:
- `学习资料.zip`
- `https://example.com`
- `ABCDEFGH`
- `qwer`

李四 下载了 `学习资料.zip`

李四 复制网页URL `https://example.com`，到浏览器中访问

李四 在网页 `Code` 处填写了 内容访问密码 `ABCDEFGH`，之后点击 `Pull`

李四 在 `文本` 处看到了 压缩包密码前段 `1234567890`
![图片](__LmgzsDocs_STATIC_ASSET_SERVER__/__CUR_DIR__/images/3.png)

李四 在解压压缩包时填写密码 `1234567890qwer`，成功得到了文件

### 对话 ASCII 艺术
```txt
+============================+
| 李四: 泄密来！             |
|                            |
|       [学习资料.zip] :张三 |
|  https://example.com :张三 |
|             ABCDEFGH :张三 |
|                 qwer :张三 |
|                            |
|   - 李四 接收了 --------   |
|   ----- [学习资料.zip] -   |
|                            |
|     密码前段在链接里 :张三 |
|       qwer是密码后段 :张三 |
|           节制一点！ :张三 |
+----------------------------+
| |                       -> |
+============================+
```

### 注意事项
- 如果使用 网页剪贴板，应该注意是否有 "阅后即焚" 的功能，如果没有 "阅后即焚" 的功能，那么可以主动覆盖，使用相同的 内容访问密码 重新保存无关内容。(时间差，社交平台审计员之后去翻聊天记录，虽然能得到 URL，但点进去时已经没内容了)

- 大多社交平台在发送 URL 时，会自动抓取该网页的 "标题" 或 "预览图" 等，这就是为什么在发送 网页剪贴板 URL 时应该注意要删除后面的 URI，让他人手动输入密码获取内容

- 压缩包密码不能太简单，不管是前段还是后段，都应该足够复杂

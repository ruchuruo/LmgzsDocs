# 高斯模糊
::: info
- 将图片模糊处理
- 可用于打码
:::
::: tip
- 本文将使用 `mogrify` 批量处理
- 使用 `mogrify` 时，输入文件 一定要放在命令末尾
:::





## 整张图片
```ps
magick `
mogrify `
-path .\out\ `
-blur 0x15 `
.\in\*.png
```
- `mogrify`    处理多文件
- `-path`      输出目录
- `-blur`      模糊半径
- `.\in\*.png` 输入文件

将 `in/` 目录中的所有 png 文件模糊处理 并输出到 `out/` 目录





## 选定区域
```ps
magick `
mogrify `
-path .\out\ `
-region 60x3000+0x0 `
-blur 0x15 `
-region 40x3000+430x0 `
-blur 0x15 `
.\in\*.png
```
```c
图片坐标
.--------------------+
|(0,0)      (100,0)  | ↑
|                    | y
|(0,100)    (100,100)| ↓
+--------------------+
        ← x →        
```
- `mogrify`    处理多文件
- `-path`      输出目录
- `-region`    选区 设置后续操作适用的区域
    - -region `选区宽`x`选区高`+`图片x`x`图片y`
- `-blur`      模糊半径
- `.\in\*.png` 输入文件

将 `in/` 目录中的所有 png 文件 选定多个位置模糊处理 并输出到 `out/` 目录

提示:

`-region XxX+XxX -blur 0xX` 先圈出第一个区域，立刻进行模糊处理。

`-region XxX+XxX -blur 0xX` 再圈出第二个区域，立刻进行模糊处理

`+region` 删除先前设置的任何区域，如果后续还有其他全局操作

# 格式转换
::: info
- 将图片格式转换成另一种格式
:::





## 单个转换
### 输出到当前目录
```sh
magick 1.png 1.webp
```
- `1.png`  输入文件
- `1.webp` 输出文件

将 `1.png` 转换为 webp 格式 并保存为 `1.webp`





## 批量转换
::: tip
- 使用 `mogrify` 时，输入文件 一定要放在命令末尾
:::

### 输出到当前目录
```sh
magick mogrify -format webp *.png
```
- `mogrify` 处理多文件
- `-format` 转换为的格式
- `*.png`   输入文件

将当前目录中的所有 png 文件转换成 webp 并输出到当前目录

### 输出到指定目录
```ps
magick `
mogrify `
-path .\out\ `
-format webp `
.\in\*.png
```
- `mogrify`    处理多文件
- `-path`      输出目录
- `-format`    转换为的格式
- `.\in\*.png` 输入文件

将 `in/` 目录中的所有 png 文件转换成 webp 并输出到 `out/` 目录

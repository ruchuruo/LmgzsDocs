# 修改个性化设置





## 任务栏

### 合并任务栏按钮
1. 注册表编辑器
```c
HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Advanced
```

2. 新建 或 修改 `TaskbarGlomLevel`
- `新建` -> `DWORD (32位)值` -> 命名为 `TaskbarGlomLevel`
- `修改` -> `TaskbarGlomLevel` -> 基数 `十六进制` -> 数值数据 `2`

`0` 始终合并按钮  
`1` 任务栏已满时  
`2` 从不  

3. 重启电脑 或是 资源管理器

# 自动换行
::: info
处理长文本行时，无需水平滚动即可查看完整内容
:::





## 开启/关闭
打开一个包含长文本行的文件

使用快捷键 `Alt + Z` 切换自动换行显示





## 问题
### 开启自动换行后 字符超出可视范围
- [VSCode 中文自动换行问题](https://github.com/subframe7536/maple-font/issues/173)

#### 方法1
更换字体

#### 方法2
打开设置

编辑
- `Editor: Wrapping Strategy`

选择
- `advanced`

##### 设置说明
`Editor: Wrapping Strategy`
- 控制计算换行位置的算法。请注意，在辅助功能模式下，高级版将用于提供最佳体验。

`simple`
- 假定所有字符的宽度相同。这是一种快速算法，适用于等宽字体和某些字形宽度相等的文字(如拉丁字符)。

`advanced`
- 将换行位置计算委托给浏览器。这是一个缓慢算法，可能会导致处理大型文件过程中失去响应，但它在所有情况下都正常工作。

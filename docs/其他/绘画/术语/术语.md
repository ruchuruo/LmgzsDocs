# 术语

---

###### Horizon Line (HL) *(地平线)*
- 地面与天空的分隔线

###### Vanishing Point (VP) *(消失点)*
- 又称 灭点
- 透视图中，在两条平行的线条中，两个线条会消失在远方的一点。

###### Left Vanishing Point (LVP) *(左消失点)*
- 又称 灭点
- 透视图中，在两条平行的线条中，两个线条会消失在远方的一点。
- 在两点透视或三点透视中

###### Right Vanishing Point (RVP) *(右消失点)*
- 又称 灭点
- 透视图中，在两条平行的线条中，两个线条会消失在远方的一点。
- 在两点透视或三点透视中

###### Central Vanishing Point (CVP) *(中心消失点)*
- 又称 灭点
- 透视图中，在两条平行的线条中，两个线条会消失在远方的一点。
- 在一点透视中

###### Diagonal Vanishing Point (DVP) *(对角线消失点)*
- 从SP点画一条这个方形的对角线，平分每一边为45°。以观察点为圆心每个旋转不同度数的方形都有自己特定的消失点，这些称为 对角线消失点(DVP)，每个旋转的方形都会有一个。

###### Station Point (SP) *(视点)*
- 镜头的位置

###### Point of View (POV) *(决定视点)*
- 观察立场，用来指代 "整个观察视角 / 视角系统" 的宏观概念，艺术创作中对 视点 与 视线 组合的习惯性通称。
- 不是几何作图中的某个辅助点
- 交流构图时常用，比如：这里我们换一个低角度的 POV，能让角色看起来更有压迫感。

###### Line of Sight *(视线)*
- 镜头朝向，从 视点 引出

###### Cone of Vision (COV) *(视锥)*
- 以 视点 为顶点，视线 方向为轴线向外扩散形成的一个锥形区域
- 建议 60°，绘画中常用的视域，图形不会出现太大的变形

###### Picture Plane (PP) *(画平面)*
- 图像被记录的一个面，想象成它是一幅垂直钉在视线上的玻璃。
- 在玻璃上画你在玻璃后看到的东西。光线从眼睛穿过 画平面，到达物体。你要做的就是在 画平面 上记录这些转换点，这就是透视画法。
- 物体的光线穿过 画平面 汇聚到 视点，在 画平面 上留下的投影就是最终呈现在画纸上的透视图形。

###### Low Distortion *(低失真)*
- 图形没有出现太大的变形

###### Strong Distortion *(强烈失真)*
- 图形出现强烈变形，广角镜头

###### Minor Axis *(短轴)*
- 一个椭圆有 一条短轴 和 一条长轴
- 短轴 是在用透视构造圆形时最重要的一根线
- 短轴 从椭圆较窄方向将椭圆一分为二，而 长轴 则从椭圆较宽方向将椭圆一分为二。

###### Major Axis *(长轴)*
- 一个椭圆有 一条短轴 和 一条长轴
- 短轴 从椭圆较窄方向将椭圆一分为二，而 长轴 则从椭圆较宽方向将椭圆一分为二。

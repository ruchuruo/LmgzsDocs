# 绘画

> 绘画的魅力在于它能超越语言和文字，让你拥有不同的交流方式。通过绘画可以让你展示事物的表象和本质。仅用一只笔和餐巾纸就可以振奋他人。
> ......<br>
> 绘画几乎是人类的天性，其中一部分人在绘画的道路上从未停下。
> ......<br>
> 带着热情从最基础的练习来开始掌握这拥有4000年的历史的上古技能。当你掌握了这些并教给他人，就打开了通往不同人心中奇妙世界的大门。
> <br>
> `Scott Robertson - How to Draw: p8`

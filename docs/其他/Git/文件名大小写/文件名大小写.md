# 文件名大小写

## 问题
Windows 系统 默认是不区分文件大小写

`README.md` 和 `readme.md` 是同一个东西

假设修改文件名，将 `FileName.txt` 修改成 `filename.txt`，git 无法查看到更改





## 解决办法
### 方法1
使用 `git mv` 重命名
```sh
git mv
```
```sh
# 1. 先把文件名改成一个临时名字
git mv FileName.txt temp_filename.txt

# 2. 再把临时名字改成想要的名字
git mv temp_filename.txt filename.txt
```

查看 Git 仓库当前状态
```sh
git status
```
```log
> git status
On branch main
Your branch is up to date with 'origin/main'.

Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        renamed:    "files/FileName.txt" -> "files/filename.txt"
```

### 方法2
修改 Git 配置文件

当前项目配置文件 或 全局配置文件
```toml
[core]
    ignorecase = false
```

查看是否生效
```sh
git config core.ignorecase
```
```log
> git config core.ignorecase
false
```

### 方法3
删除文件 或 重命名整个文件夹

然后暂存

恢复文件

然后暂存

查看 Git 仓库当前状态
```sh
git status
```
```log
> git status
On branch main
Your branch is up to date with 'origin/main'.

Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        renamed:    "files/FileName.txt" -> "files/filename.txt"
```

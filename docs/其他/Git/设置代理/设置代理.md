# 设置代理





## 方法1 修改全局配置文件
::: info
- 全局配置文件在用户目录
```c
~/.gitconfig
```
:::

### 修改全局配置文件
无需认证的代理
::: code-group
```toml [.gitconfig]
# 示例

[http]
    proxy = http://代理地址:端口

[https]
    proxy = https://代理地址:端口
```
```toml [.gitconfig]
# 示例

[http]
    proxy = http://192.168.0.123:4321

[https]
    proxy = https://192.168.0.123:4321
```
:::

需要认证的代理
::: code-group
```toml [.gitconfig]
# 示例

[http]
    proxy = http://用户名:密码@代理地址:端口

[https]
    proxy = https://用户名:密码@代理地址:端口
```
```toml [.gitconfig]
# 示例

[http]
    proxy = http://user:98765@192.168.0.123:4321

[https]
    proxy = https://user:98765@192.168.0.123:4321
```
:::

### 取消设置全局代理
注释或删除配置项





## 方法2 命令行
### 设置全局代理
无需认证的代理
::: code-group
```sh
git config --global http.proxy http://代理地址:端口
```
```sh
git config --global http.proxy http://192.168.0.123:4321
```
:::

需要认证的代理
::: code-group
```sh
git config --global http.proxy http://用户名:密码@代理地址:端口
```
```sh
git config --global http.proxy http://user:98765@192.168.0.123:4321
```
:::

### 取消设置全局代理
```sh
git config --global --unset http.proxy
```





## 注意事项
- 如果用户名或密码中包含特殊字符，导致 Git 解析 URL 失败，可以进行 URL 编码

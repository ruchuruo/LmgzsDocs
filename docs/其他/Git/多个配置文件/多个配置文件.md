# 多个配置文件
::: info
- 为不同目录使用不同配置文件
- 全局配置文件在用户目录
    ```c
    ~/.gitconfig
    ```
:::





### 创建多个配置文件
在用户目录创建文件夹，文件夹名字随意
```c
~/gitconfig/
```

在文件夹内创建git配置文件，文件名字随意
```c
~/gitconfig/
    MyProject1.gitconfig
    MyProject2.gitconfig
```

修改配置文件
```toml
# MyProject1.gitconfig

[user]
    name = zhangsan
    email = zhangsan@example.com
```
```toml
# MyProject2.gitconfig

[user]
    name = lisi
    email = lisi@example.com
```

### 修改全局配置文件
条件包含，为不同目录使用不同配置文件
```toml
# .gitconfig

[includeIf "gitdir:D:/Project1/"]
    path = ~/gitconfig/MyProject1.gitconfig

[includeIf "gitdir:D:/Project2/"]
    path = ~/gitconfig/MyProject2.gitconfig
```

### 验证
前往条件包含中的目录，查看项目配置，没有时显示全局配置
```sh
git config user.name
git config user.email
```

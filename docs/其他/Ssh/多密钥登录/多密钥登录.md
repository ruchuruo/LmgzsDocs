# 多密钥登录
::: info
- 使用不同密钥登录不同服务器 
:::





### 创建/打开 配置文件
```c
~/.ssh/config
```

### 填写内容
```c
Host 别名
    HostName        域名/ip
    Port            端口
    User            登录用户名
    IdentityFile    私钥路径

Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/zhangsan.key

Host gitlab.com
    HostName gitlab.com
    User git
    IdentityFile ~/.ssh/lisi.key

Host gitgud.io
    HostName ssh.gitgud.io
    User git
    IdentityFile ~/.ssh/wangwu.key
```

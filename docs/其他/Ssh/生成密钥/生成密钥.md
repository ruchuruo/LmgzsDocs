# 生成密钥
::: info
公钥和私钥用于实现无密码登录和身份验证
:::





### 生成新的密钥
#### 输入命令
```sh
ssh-keygen -t ed25519 -C "your_email@example.com"
```
```log
Generating public/private ed25519 key pair.
Enter file in which to save the key (~/.ssh/id_ed25519):
```
- `-t` 算法
- `-C` 邮箱

不提供邮箱将会使用主机名

#### 输入参数1 保存位置
``` log
Enter file in which to save the key (~/.ssh/id_ed25519):.ssh/zhangsanKey.key
```
Enter file in which to save the key(输入保存密钥的文件)

按 Enter 键接受默认文件位置

推荐自定义文件名字

#### 输入参数2 安全密码
```log
Enter passphrase (empty for no passphrase):
Enter same passphrase again:
```
Enter passphrase (empty for no passphrase)(安全密码 (留空表示无密码))

Enter same passphrase again(再次输入相同的密码)

### 得到新的密钥
```c
~/.ssh/
    zhangsanKey.key     私钥
    zhangsanKey.key.pub 公钥
```
